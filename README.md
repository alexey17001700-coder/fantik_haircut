# 🍭 Детская парикмахерская «Фантик»

Сайт-визитка детской парикмахерской: услуги, цены, преимущества, галерея и запись по телефону.

## 🔗 Сайт
https://alexey17001700-coder.github.io/fantik_haircut/

## Что внутри
- **Герой** — название, слоган, кнопка записи, плавающие иконки и пузыри на фоне.
- **Услуги** — 6 карточек с ценами (стрижка, первая стрижка, косички, мальчикам, окрашивание, семейная).
- **Почему мы** — 6 причин: мультики, игрушки, безопасность, скорость, подарки, без слёз.
- **Галерея** — цветные плитки с анимацией.
- **Запись** — яркий блок с телефоном.
- **Контакты** — телефон, часы работы, возраст, оплата.
- Адаптив под телефон, анимации при скролле, шрифты Baloo 2 + Nunito.

## Файлы
- `index.html` — весь сайт в одном файле (без библиотек).
